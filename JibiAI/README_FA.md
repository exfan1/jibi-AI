# Jibi AI 0.5 MVP

نسخه تستی پیشرفته برای Android 8+ / API 26+ با target SDK 35.

## قابلیت‌های این نسخه
- فرمان صوتی فارسی و TTS
- Planner چندمرحله‌ای
- کنترل Accessibility: Home/Back/Recent/Notifications/Click/Type/Scroll
- Notification Listener برای نگهداری اعلان‌های اخیر
- تماس و پیام با تأیید کاربر
- دوربین، فلش، آلارم، وب و نقشه
- حافظه محلی
- اتصال اختیاری به API سازگار با OpenAI
- صفحه Self Test برای بررسی آماده‌بودن قابلیت‌ها

## Build
پروژه را در Android Studio باز کن، Gradle Sync و سپس Build APK(s) را اجرا کن.

## بعد از نصب
1. Microphone را اجازه بده.
2. Settings > Accessibility > Jibi AI را فعال کن.
3. Notification Access را در صورت نیاز فعال کن.
4. از داخل برنامه «🧪 تست وضعیت Jibi» را بزن.

این نسخه عمداً برای تماس و پیام قبل از بازکردن صفحه مربوطه تأیید می‌خواهد. هیچ دسترسی امنیتی اندروید دور زده نمی‌شود.
